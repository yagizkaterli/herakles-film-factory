# Asset and animation strategy

The factory uses three kinds of visual matter. They must never be confused.

## 1. Narrative GIFs

Small loops used for chapter covers, transitions, and explanatory witnesses. They are art-direction assets, not live evidence.

Required first batch:

- `trace-intake.gif` — a mark enters the story; no invented count.
- `question-hold.gif` — a quiet unresolved state; no celebratory motion.
- `receipt-return.gif` — a receipt pointer returns to the same object.
- `world-link.gif` — a visual link from film receipt to World pointer.

Each GIF gets a manifest entry with role, dimensions, palette, source relation and `evidence: narrative-only`.

## 2. Deterministic 3D scenes

Generated by Manim/ManimGL-compatible code or the HERAKLES World Three.js runtime. Geometry is derived from real source IDs and authority states.

Required first scenes:

- `context-recovery`: a contextless agent reconstructs one task from system surfaces.
- `event-to-world`: one real event moves through the World mirror.
- `authority-state`: provisional, blocked and verified states use different geometry/material rules.
- `camera-waypoint`: the camera follows the same object through question → reveal → consequence.

## 3. World-native motion

The World runtime owns live agent movement, parcel placement, receipt-bound construction and EON camera focus. Film Factory may request a read-only source snapshot; it never invents or writes canonical geometry.

## Generation gates

1. A source manifest exists.
2. The asset role is explicit.
3. Art-direction assets are visibly marked non-canonical.
4. 3D objects have stable IDs and authority states.
5. MP4/GIF output has a receipt and QA result.
