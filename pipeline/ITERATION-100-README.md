# 100-iteration image-to-3D loop

The 100 iterations are not 100 random pretty images. They are five measured waves. Each candidate answers one visual question about a real HERAKLES EON, paper claim, event or receipt.

ImageGen is used early because it is cheap for exploring composition and mood. The winning direction is then rebuilt in code: Three.js/World for spatial life, Manim/ManimGL-compatible code for explanatory transformations, and JSON receipts for source parity.

No generated image becomes a live World fact. No 3D object becomes solid without the authority matrix and receipt gate.

Canonical contract: `canonical/iteration-100-imagegen-to-3d.v1.json`.
