# Audience-first film contract

The viewer is assumed to know nothing about HERAKLES, Lobi, EON, BILD, agents, or Manim.

## The first ten seconds

The viewer must be able to answer two questions without sound:

1. What concrete thing is on screen?
2. What change is it trying to make?

No acronym, model name, architecture diagram, result badge, or “today we will explain” opening is allowed.

## Every film beat

Each beat has exactly one visible verb:

`observe -> obstruct -> predict -> transform -> verify -> return`

If a motion does not carry that verb, it is removed.

## Translation table

| Internal object | Audience-facing witness |
|---|---|
| task card | one piece of work waiting to be done |
| trace/event | a mark left by the previous worker |
| agent | the next worker who reads that mark |
| receipt | proof that the work actually crossed the gate |
| EON | the order in which the world changed |
| provisional | a plan/outline, not a built thing |
| verified | a built thing with a source |
| blocked | a visible stop, not an empty screen |

## Film family structure

- `origin`: why this exists, one sentence.
- `witness`: one real event or receipt.
- `mechanism`: one transformation of that witness.
- `consequence`: what changed in the world.
- `limit`: what this film did not prove.

Long-form films may chain these micro-films, but each chapter must remain understandable alone.

## Anti-confusion gates

- Never show a generated image as if it were a live system state.
- Never show a solid world object without verified receipt/evidence/review authority.
- Never use an acronym before its concrete witness.
- Never put a result in metadata before the viewer has predicted the question.
- Never replace a real object with an unrelated chart.

## Final frame

The last frame reuses the first witness, now carrying its consequence and source pointer. It must be redrawable from memory.
