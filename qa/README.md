# QA gates

- `silent-open`: at ten seconds, an outsider can name the concrete object and its problem.
- `question-before-machinery`: no abstraction appears before its visible witness.
- `identity-continuity`: object IDs survive every representation change.
- `honesty`: exact/failure/verified claims have a nearby source and receipt.
- `reduced-motion`: final frame still communicates the proposition.
- `source-parity`: visible IDs, counts and paths match the source manifest.
- `world-link`: pointer exists; no canonical write occurred.

Browser capture is mandatory for final QA. If capture is unavailable, the receipt is `BLOCKED`, never `PASS`.
